## 🌟 About the Project

**D Care Dental Clinic** is a high-authority, conversion-focused web application designed for a modern dental practice in Chennai. It combines a premium aesthetic with functional tools to bridge the gap between patients and professional dental care.

### Who is this for?
- **Patients**: Looking for expert dental specialists, transparent service information, and easy booking options.
- **Clinic Owners**: Wanting a professional digital presence that reflects their quality of care and drives appointments.

## 🚀 How it Works

The website is built to provide a seamless "Patient Journey":
1. **Discovery**: Patients explore specialized services (Orthodontics, Implants, etc.) and meet the expert team.
2. **Social Proof**: Real patient testimonials and Google reviews build trust.
3. **Engagement**: Interactive Google Maps and detailed location info help patients find the clinic easily.
4. **Conversion**: Patients can book appointments via a custom form or instant WhatsApp support.

## 🛠️ Tech Stack

- **Core**: React 19 + TypeScript
- **Styling**: Tailwind CSS 4 (with modern Glassmorphism effects)
- **Animations**: Framer Motion (Motion) for smooth reveals
- **Icons**: Lucide React
- **Forms**: React Hook Form + Zod validation
- **Build Tool**: Vite

## 💻 Local Development

**Prerequisites:** [Node.js](https://nodejs.org/) (Latest LTS)

1. **Clone the repository:**
   ```bash
   git clone https://github.com/VigneshwarRamadoss/D-Care-Dental-Clinic.git
   cd D-Care-Dental-Clinic
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Environment Setup:**
   Create a `.env.local` file and add your Gemini API key:
   ```env
   GEMINI_API_KEY=your_key_here
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) (or 3001) in your browser.
